# MediaFetch 2.0.1

MediaFetch 2.0.1 fixes the desktop download layout while preserving the existing mobile layout.

## Fixed

- Center the desktop download form with a maximum width of 960 pixels and surrounding spacing.
- Center the downloader IP check and download-mode tabs, with the input fields below them.
- Hide the mobile navigation toggle on desktop, where it appeared as a tall strip beside the navigation.

## Release metadata

- Keep the app and package versions aligned at 2.0.1.
- The app manifest declares Nextcloud 32–36 and PHP 8.2–8.5. This metadata change does not constitute runtime verification on Nextcloud 36.

## Validation

- Production frontend build and existing torrent-action and localization tests passed for the layout change.
- Browser fixture checks at 390, 768, 1024, 1280 and 1920 pixels confirmed centered desktop layout and unchanged mobile element positions.
- Verification in a running Nextcloud instance remains outstanding.

The automatically generated GitHub archive contains built frontend assets and PHP dependencies. It is **not signed for the Nextcloud App Store**; App Store signing and submission remain separate steps.
