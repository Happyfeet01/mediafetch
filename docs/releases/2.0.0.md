# MediaFetch 2.0.0

MediaFetch 2.0 brings a redesigned, multilingual Nextcloud download interface, graphical yt-dlp configuration and expanded legal-use torrent search options.

## What's new

- A graphical yt-dlp settings assistant alongside a compact, expandable advanced options panel.
- Per-download presets for YouTube videos, video playlists and YouTube Music tracks, albums and playlists (MP3, available ID3 metadata and thumbnails).
- A cleaner mobile download workflow: paste a link, choose a target folder and optional preset, then start the download.
- Internet Archive and Academic Torrents searches added beside existing torrent providers, with a neutral usage-rights disclaimer.
- An aria2 option to stop seeding **after** downloads finish. It does not prevent uploading while downloading.
- German and English translations throughout the interface.

## Fixes and stability

- Fixed the blank app page caused by search provider data containing spaces.
- Fixed Academic Torrents caching via the Nextcloud app data factory and improved Archive search queries.
- Fixed invalid yt-dlp argument handling with empty thumbnail options and invalid `parse-metadata` filename templates.
- Prevented Safari on iPhone from zooming the media URL field on focus.
- Added automated PHP 8.2–8.5, frontend, translations, search and download-preset regression checks.

## Requirements

- Nextcloud 32–35 (respect the corresponding Nextcloud PHP compatibility range).
- PHP 8.2–8.5, aria2 and yt-dlp; ffmpeg for media conversions.
- Optional Academic Torrents search requires the PHP XMLReader extension.

**Important:** The attached GitHub tarball contains built frontend and PHP dependencies but is **not signed for the Nextcloud App Store**. Publishing/updating the App Store package is a separate signing and submission process.
