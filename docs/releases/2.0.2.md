# MediaFetch 2.0.2

MediaFetch 2.0.2 is a maintenance release. It contains no feature or user-facing code changes.

## Fixed

- Pinned the CI pipeline to ubuntu-24.04 and Node 22 after the GitHub-hosted Ubuntu 26 runner image broke npm installs in October 2026.

## Release metadata

- Keep the app and package versions aligned at 2.0.2.
- The app manifest continues to declare Nextcloud 32–36 and PHP 8.2–8.5.

## Validation

- All CI checks (PHP 8.2–8.5, frontend build) pass on the pinned runner image.
- Verification in a running Nextcloud instance remains outstanding.

The automatically generated GitHub archive contains built frontend assets and PHP dependencies. It is **not signed for the Nextcloud App Store**; App Store signing and submission remain separate steps.
